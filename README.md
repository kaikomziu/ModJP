# ModJP — MOD日本語化パック (Minecraft 1.20.1 / Forge)

英語のままになっているMODの文字を日本語にするリソースパックです。
**478 MOD・約9.3万項目**に日本語訳を追加します(ATM8系のMODを多数含む。ATM11のMODも一部対応)。

- MOD本体(jar)は一切いじりません。MODを更新しても壊れません。
- MODにもともと入っている公式の日本語訳は上書きしません(足りない部分だけ足します)。
- 入っていないMODの分は単に無視されるので、478 MODを全部入れていなくても使えます。

## ダウンロード

[Releases](../../releases/latest) から `ModJP_1.20.1_v1.4.zip` をダウンロードしてください。

## 使い方

1. zipを**解凍せずに**、インスタンスの `resourcepacks` フォルダに入れる
   (CurseForgeならインスタンスを右クリック →「フォルダを開く」→ `resourcepacks`)
2. ゲームの「設定 → 言語」を「日本語」にする
3. 「設定 → リソースパック」で「MOD日本語化パック」を有効(右側)にする
   ※他のリソースパックより上に置いてください

対応MODの一覧は zip 同梱の `manual_ja.txt`(説明書) を見てください。

## 誤訳の報告

[Issues](../../issues) に「MOD名・表示されている文字・どう直すべきか」を書いてください。

## 中身

| フォルダ | 内容 |
|---|---|
| `pack/` | リソースパック本体(`assets/<MOD>/lang/ja_jp.json`) |
| `tsv/` | 手訳の原稿(TSV) |
| `tr/` | 生成済みの訳データ(JSON) |
| `*.py` | 抽出・生成・検査・パッケージ化のスクリプト(手順は [README_dev.md](README_dev.md)) |

各MODの英語原文はこのリポジトリには含めていません。
他のMODの公式訳ファイルは一切同梱していません(訳を追加したのは公式訳が無いキーだけです)。

## 対象バージョン

Minecraft 1.20.1 / Forge(リソースパック形式 15)
