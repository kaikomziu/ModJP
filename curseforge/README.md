## ライセンス

CurseForge では選択が必須です。どちらかがおすすめです。

- **All Rights Reserved**: 再配布・改変を許可しない。迷ったらこれ。
- **MIT**: 誰でも改変・再配布してよい(作者表記は必要)。他の人に訳を直してもらったり、別パックに組み込んでもらったりしたい場合。

GitHub のリポジトリにも同じライセンスを付けておくと揃います。

## 審査で止められにくくするためのポイント

- 説明文に「MOD本体を含まない」「公式訳を上書きしない」と書いてある(description.md に記載済み)
- 他人のファイルを含まない(v1.3 で Twilight Forest の公式訳を除外済み)
- スクリーンショットを最低2〜3枚付ける(下の案)

## スクリーンショット案

**`____ (2)` は起動しない前提なので、撮影はふだん遊んでいるインスタンスで。** 同じMODが入っていれば日本語になります。
F2 でスクリーンショット、F1 で HUD を消せます。1枚目は CurseForge の一覧にも出るので一番映えるものを。

| # | 画面 | 撮り方 | 見せたいこと |
|---|---|---|---|
| 1 | **ビフォー/アフター比較** | 同じアイテムのツールチップを、パック無効(英語)と有効(日本語)で1枚ずつ撮り、左右に並べて1枚にする | パックの効果が一目でわかる。一覧のサムネイル向き |
| 2 | **JEI(アイテム一覧)** | インベントリを開いて JEI の右側一覧を表示。Tetra や Simply Swords など名前が多く並ぶページ | アイテム名がまとめて日本語になっている |
| 3 | **機械のGUI** | Mekanism や PneumaticCraft、AE2 の機械を右クリックして画面を開く | ボタン・設定項目まで日本語 |
| 4 | **ガイドブック** | Patchouli 系(Botania の植物辞典、Theurgy、Hexerei など)の説明ページを開く | 長い説明文まで訳してある |
| 5 | **進捗画面** | L キーで進捗を開き、Twilight Forest のタブを表示 | 進捗のタイトル・説明が日本語 |
| 6 | **FTB Quests**(入っていれば) | クエスト画面 | Modpack を遊ぶ人に刺さる |
| 7 | **リソースパック画面** | 設定 → リソースパックで、ModJP が有効になっている状態 | 導入方法の説明として使える |

### 撮るときのコツ

- GUI スケールを「3」くらいにすると文字が読みやすい
- ウィンドウを 1920×1080 にして撮ると CurseForge 上で見やすい
- 1 のビフォー/アフターは、ペイントなどで2枚を横に並べて1枚の画像にする。「英語 → 日本語」と文字を入れるとなおよい
- 各スクショには CurseForge 上でタイトルを付けられるので「JEIのアイテム名」「機械の画面」などと書いておく
